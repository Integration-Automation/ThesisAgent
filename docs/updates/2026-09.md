## U-20260922-02 · 2026-09-22 · Dedup on every identity key, with field provenance · #done #dedup

- **What**: `thesisagents.core.dedup.dedupe` now groups papers on every identity key a record carries (`Paper.identity_keys()`: DOI, version-stripped arXiv ID, fuzzy title + first-author surname + year hash) instead of only the strongest one, so a DOI-less ACM record and the DOI-carrying OpenAlex record of the same paper merge, and a later record can join two earlier groups. A fuzzy-only match never merges records whose DOIs (or arXiv IDs) disagree, and blank / punctuation-only titles never link. Every backfilled field is recorded as a `FieldProvenance(field, source, source_id)` in the new `Paper.provenance` tuple, which round-trips through `to_dict` / `from_dict`. Same commit: `Paper.bibtex_key()` falls back to `anon` for a blank author string instead of raising `IndexError`; `Paper.from_dict()` names missing required fields in a `ThesisAgentsError`; new `Query.clamp_max_results()`; `ranking.rank()` defaults the recency base to the current UTC year instead of a hard-coded 2026; unused `CACHE_TTL_SECONDS` removed; the pptx export description now says light mode is the default. Part of `progress.md` #1.

## U-20260922-03 · 2026-09-22 · Contain per-source, per-paper and write failures · #done #robustness

- **What**: one bad source, paper or file no longer throws away the rest of a run. `pipeline._safe_search` treats any unexpected exception from a source plugin (for example a `KeyError` after an upstream schema change) like a `FetchError`: that source returns nothing and the others keep their results. `download_pdfs` and `resolve_oa_pdfs` gather with `return_exceptions=True`; a failed download becomes a skipped result with reason `error_<ExceptionType>`, and a failed OA lookup keeps the paper without a `pdf_url`. `export_collection` turns an `OSError` on write (for example the previous `.xlsx` still open in Excel) into an `ExportError` that says what to do. The pptx exporter names the `PaperSummary` field whose shape broke a rich slide builder and pads ragged table rows instead of raising `IndexError`. The xlsx exporter strips control characters openpyxl refuses. `review_deck` raises `ExportError` for a missing or non-pptx file, and `review` keeps reporting the other decks when one path is unreadable. Part of `progress.md` #1.
- **Files**: `thesisagents/core/pipeline.py`, `thesisagents/core/pdf_download.py`, `thesisagents/core/oa_resolver.py`, `thesisagents/exporters/__init__.py`, `thesisagents/exporters/pptx.py`, `thesisagents/exporters/xlsx.py`, `thesisagents/exporters/review.py`, `tests/test_pipeline.py`, `tests/test_pdf_download.py`, `tests/test_oa_resolver.py`, `tests/test_exporters.py`, `tests/test_review.py`.

## U-20260922-04 · 2026-09-22 · Treat --export pdf as the PDF download stage · #done #cli #mcp

- **What**: `pdf` is listed by `--list-exports` / `list_exports` but has no exporter class, so `--export pdf` used to fail with "no exporter registered for this format" after the whole search and download had run. The CLI now turns `pdf` into the download flag; `--export pdf` on its own is a download-only run (`_run_download_only`) that exits 1 when nothing was found or no PDF was saved. The MCP `export` tool drops `pdf` from the format list and, when nothing renderable is left, raises an error pointing at `download_pdfs`. The CLI `--pdf <directory>` mode and the MCP `export` / `download_pdfs` tools build their synthetic `Query` with `Query.clamp_max_results`, so more than 200 papers no longer fail on the per-source page-size check; `download_pdfs` also sorts its source tuple and skips blank sources. The `--source` help text now describes the key-gated and default-on plugins correctly. Part of `progress.md` #1.
- **Files**: `thesisagents/cli.py`, `thesisagents/mcp/server.py`, `tests/test_cli.py`, `tests/test_mcp_tools.py`.
- **Evidence**: new tests `test_cli_export_pdf_downloads_instead_of_failing`, `test_cli_export_pdf_alone_is_a_download_only_run`, `test_export_ignores_the_pdf_pseudo_format`, `test_export_with_only_pdf_points_at_the_download_tool`, `test_export_accepts_more_papers_than_the_page_size_cap`.
